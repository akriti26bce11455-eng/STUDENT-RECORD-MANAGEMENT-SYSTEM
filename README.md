## ✨ Features

- **Add Student Record:** Input student details (Roll Number, Name, Class) along with marks for Math, Science, and English[cite: 1].
- **Automatic Calculations:** 
  - Computes total marks and average percentage[cite: 1].
  - Assigns grades (`A+`, `A`, `B`, `C`, `D`, `E`, `F`) based on score boundaries[cite: 1].
  - Marks status as **Fail** if any individual subject score is below 35[cite: 1].
- **Show All Records:** Display details and grade reports for all stored students[cite: 1].
- **Search Student:** Search and view specific student records using their Roll Number[cite: 1].
- **Delete Student:** Remove a student record from the system[cite: 1].
